Bike

Measure it: chalk the tire, sit on the bike, roll one full turn, measure between marks. 20x1.75 is about 1515 mm.

Start and stop

Recording starts when the wheel reaches the launch speed within 4 seconds of rolling after standing still that long. Walking or rolling slowly to the gate stays below it. Set "stand still" to 0 to start on speed alone.

Logger

Each run slot holds about 65 s at 250 Hz, 32 s at 500 Hz, counting the 3 s before the start. The logger keeps the newest 7 runs and overwrites the oldest.
