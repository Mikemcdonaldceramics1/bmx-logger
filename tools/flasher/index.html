BMX Logger installer

Installs the latest logger firmware over USB.

  1. Plug the logger into this computer with the USB cable.
  2. Close Arduino IDE or anything else using the board.
  3. Click Install, pick the CP2102 / Silicon Labs port, then Install again.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.

Open this page over https.

If it can't connect: hold the BOOT button on the board, tap EN, release BOOT, and try again. Installing over USB clears the runs and settings stored on the logger. After this, the phone app can update the logger over Bluetooth (Settings → Firmware).
